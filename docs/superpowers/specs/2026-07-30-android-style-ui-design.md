# Android 风格 UI 设计

## 概述

创建一个类似 Android 的手机 UI 界面，包含状态栏、应用图标网格、底部导航栏和通知中心。使用 LVGL v9.5.0 实现，支持 PC 模拟和 STM32 硬件。

## 目标

- 创建类似 Android 的主屏幕体验
- 支持下拉通知中心
- 应用图标有动画效果
- 底部导航栏有交互反馈
- 保持 PC 和 STM32 的代码共享

## 非目标

- 不实现完整的 Android 系统功能
- 不实现多任务切换
- 不实现应用内导航

## 组件设计

### 状态栏

**实现：**
- 使用 `lv_label` 显示时间和文字
- 使用 LVGL 符号显示图标
- 固定在屏幕顶部

**样式：**
- 背景色：浅灰色 (#F5F5F5)
- 文字颜色：黑色 (#000000)
- 字体：Montserrat 12

### 应用图标网格

**实现：**
- 使用 `lv_obj` 创建图标容器
- 使用 `lv_label` 显示图标和名称
- 使用 `lv_anim` 实现点击动画

**样式：**
- 图标大小：60x60
- 名称字体：Montserrat 10
- 网格间距：20px

### 底部导航栏

**实现：**
- 使用 `lv_btn` 创建按钮
- 使用 LVGL 符号显示图标
- 固定在屏幕底部

**交互：**
- 点击按钮有缩放动画
- 当前页面对应的按钮高亮显示
- 点击返回按钮返回上一个页面

**样式：**
- 背景色：白色 (#FFFFFF)
- 图标颜色：灰色 (#757575)
- 高亮颜色：蓝色 (#2196F3)
- 图标大小：24x24

### 通知中心

**实现：**
- 使用 `lv_obj` 创建可滚动容器
- 使用 `lv_btnmatrix` 创建快速设置按钮
- 使用 `lv_list` 显示通知列表

**交互：**
- 从屏幕顶部下拉打开通知中心
- 点击快速设置按钮切换状态
- 点击通知可以打开对应应用
- 向上滑动关闭通知中心

**样式：**
- 背景色：白色 (#FFFFFF)
- 快速设置按钮：圆角矩形
- 通知卡片：带阴影的卡片样式

## 导航流程

```
主屏幕 → 点击应用图标 → 应用页面
       → 滑动切换应用 → 下一个应用
       → 点击返回 → 主屏幕
       → 下拉 → 通知中心
       → 点击底部导航 → 切换功能
```

## 平台兼容

### PC 模拟

- 所有 UI 代码保持平台无关
- 鼠标拖拽模拟滑动
- 控件交互只输出日志

### STM32 硬件

- 触摸滑动正常工作
- LED 控件操作实际控制 LED
- 其他控件交互输出日志

## 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 内存占用大 | 使用部分渲染模式，优化内存使用 |
| 动画卡顿 | 优化动画性能，减少重绘区域 |
| 240x320 分辨率显示不全 | 使用滚动容器，确保所有控件可见 |
| 触摸交互不灵敏 | 调整触摸区域大小，优化触摸响应 |
