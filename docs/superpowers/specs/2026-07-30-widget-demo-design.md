# LVGL 控件演示 UI 设计

## 概述

扩展现有的 LVGL PC 模拟环境，添加一个完整的控件演示 UI。使用菜单导航方式组织不同类型的 LVGL 控件，包括输入控件、显示控件、数据控件和选择控件。

## 目标

- 展示 LVGL 各种控件的使用方法
- 提供交互式的控件演示
- 保持 PC 和 STM32 的代码共享
- 验证 LVGL 控件在 240x320 分辨率下的显示效果

## 非目标

- 不实现复杂的产品级 UI
- 不添加动画过渡效果
- 不实现数据持久化

## 页面结构

### 主菜单页面

**布局：**
```
┌─────────────────────────────┐
│      LVGL 控件演示          │
├─────────────────────────────┤
│                             │
│    ┌─────────────────┐      │
│    │  输入控件       │      │
│    └─────────────────┘      │
│                             │
│    ┌─────────────────┐      │
│    │  显示控件       │      │
│    └─────────────────┘      │
│                             │
│    ┌─────────────────┐      │
│    │  数据控件       │      │
│    └─────────────────┘      │
│                             │
│    ┌─────────────────┐      │
│    │  选择控件       │      │
│    └─────────────────┘      │
│                             │
└─────────────────────────────┘
```

**实现：**
- 使用 `lv_list` 创建菜单列表
- 每个菜单项是一个按钮
- 点击菜单项跳转到对应的子页面

### 输入控件页面

**布局：**
```
┌─────────────────────────────┐
│  < 返回    输入控件         │
├─────────────────────────────┤
│                             │
│  Slider:                    │
│  [========o---------] 50    │
│                             │
│  Switch:                    │
│  [OFF]                      │
│                             │
│  Arc:                       │
│      ╭─────╮                │
│     ╱       ╲               │
│    │    ●    │              │
│     ╲       ╱               │
│      ╰─────╯                │
│                             │
└─────────────────────────────┘
```

**控件：**
1. **Slider（滑块）**
   - 范围：0-100
   - 默认值：50
   - 显示当前值

2. **Switch（开关）**
   - 默认状态：OFF
   - 点击切换 ON/OFF

3. **Arc（旋钮）**
   - 范围：0-100
   - 默认值：50
   - 显示当前值

**交互：**
- 返回按钮：返回主菜单
- 每个控件的变化都会在控制台输出日志

**控件：**

- 返回按钮：返回主菜单

## 文件结构

```
ui/
├── ui.h                    ← UI 初始化接口
├── ui_main.c               ← 主菜单页面
├── ui_input.c              ← 输入控件页面（Slider、Switch、Arc）
├── ui_display.c            ← 显示控件页面（Bar、Spinner、LED）
├── ui_data.c               ← 数据控件页面（Chart、Table）
└── ui_selection.c          ← 选择控件页面（Dropdown、Roller）
```

## 导航机制

**页面切换：**
- 使用 `lv_scr_load_anim()` 实现页面切换动画
- 动画类型：`LV_SCR_LOAD_ANIM_MOVE_LEFT`
- 动画时间：300ms

**返回功能：**
- 每个子页面保存主菜单页面的引用
- 点击返回按钮时加载主菜单页面

**状态管理：**
- 使用全局变量 `g_current_page` 跟踪当前页面
- 每个页面初始化时更新 `g_current_page`

## 平台兼容

**PC 模拟：**
- 所有 UI 代码保持平台无关
- 控件交互只输出日志
- 不执行硬件操作

**STM32 硬件：**
- LED 控件操作实际控制 LED
- 其他控件交互输出日志
- 触摸输入正常工作

## 测试验证

**PC 模拟验证：**
1. 运行 `lvgl_pc_sim.exe`
2. 验证主菜单显示 4 个选项
3. 点击每个选项，验证子页面显示正确的控件
4. 验证返回按钮功能
5. 验证控件交互（Slider、Switch 等）

**STM32 硬件验证：**
1. 烧录到 STM32F407
2. 验证触摸交互
3. 验证 LED 控件操作实际 LED
4. 验证显示效果与 PC 一致

## 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| 页面切换卡顿 | 使用简单的切换动画，避免复杂效果 |
| 控件过多导致内存不足 | 使用部分渲染模式，优化内存使用 |
| 240x320 分辨率显示不全 | 使用滚动容器，确保所有控件可见 |
