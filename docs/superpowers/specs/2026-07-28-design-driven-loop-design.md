# 设计驱动闭环工作流设计文档

## 概述

将**设计驱动验证**功能**融合到现有的 debug_loop.py 系统**中。系统能够**读取设计文档**，**验证实现是否符合设计**，**自动修复不符合项**，**重复直到全部通过**。

**核心理念：扩展现有闭环，增加设计验证能力**

## 核心需求

| 需求 | 说明 | 实现方式 |
|------|------|---------|
| **读取设计文档** | 解析 Markdown 格式的设计文档 | 新增 DesignParser 组件 |
| **代码审查** | AI 分析代码是否符合设计 | 复用现有 Analyzer |
| **功能测试** | 运行设计文档中定义的测试用例 | 复用现有 Verifier |
| **UI 对比** | 截图对比设计稿 | 新增 UITester 组件 |
| **性能测试** | 测量性能指标 | 新增 PerformanceTester |
| **阈值判断** | 检查指标是否超过阈值 | 新增 ThresholdChecker |
| **失败修复** | 分析失败原因，AI 生成修复代码 | 复用现有 Fixer |
| **循环迭代** | 重复直到全部验证通过 | 扩展现有 Engine |

## 设计文档格式

```markdown
# 项目设计方案

## 功能需求
- [ ] LED 控制：支持开/关/闪烁
- [ ] LCD 显示：支持文字和图形
- [ ] 触摸响应：支持触摸和滑动

## 性能指标
| 指标 | 阈值 | 说明 |
|------|------|------|
| LED 响应时间 | < 10ms | LED 开启到亮起的时间 |
| LCD 刷新率 | > 30fps | LCD 刷新频率 |
| 触摸响应时间 | < 50ms | 触摸到响应的时间 |

## UI 设计
- 主界面：显示状态信息
- 设置界面：配置参数

## 测试用例
- test_led_on: LED 开启测试
- test_lcd_display: LCD 显示测试
- test_touch_response: 触摸响应测试
```

## 新增组件

### DesignParser
- 解析 Markdown 格式的设计文档
- 提取功能需求、性能指标、UI 设计、测试用例
- 输出结构化的 DesignSpec 对象

### CodeReviewer
- AI 分析代码是否符合设计文档中的功能需求
- 检查代码结构、命名规范、注释完整性
- 输出审查报告

### FunctionTester
- 运行设计文档中定义的测试用例
- 验证每个功能点是否正常工作
- 输出测试结果

### UITester
- 截取当前 UI 截图
- 与设计文档中的 UI 设计对比
- 检查布局、颜色、字体是否符合

### PerformanceTester
- 测量设计文档中定义的性能指标
- 输出性能报告

### ThresholdChecker
- 检查每个性能指标是否超过阈值
- 输出判断结果

### CodeFixer
- AI 分析验证失败的原因
- 生成修复代码
- 输出修复方案
